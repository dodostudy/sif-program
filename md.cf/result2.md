## Ⅰ. 개요

### 무엇을 만들었는가

> **"2,574건의 실제 사망·중상 재해 데이터를, 누구나 5초 안에 꺼내 쓸 수 있게"**

건설현장 위험성평가의 가장 큰 난제는 **참고할 데이터의 부재**였다.  
경험 많은 안전관리자도 전 공정을 아우르는 표준 위험요인 자료 없이는 누락을 막기 어렵고,  
협력업체 근로자는 두꺼운 PDF를 펼칠 여유조차 없다.

본 시스템은 이 문제를 정면으로 해결하기 위해 **직접 개발·배포한 웹 기반 위험성평가 지원 플랫폼**

| 항목 | 내용 |
|------|------|
| 시스템명 | SIF 건설재해 위험성평가 지원시스템 |
| 개발 주체 | 행복+ 분당발전본부 안전관리실 (자체 개발) |
| 데이터 출처 | 한국산업안전보건공단 SIF Raw 데이터 (직접 요청 확보) |
| 데이터 규모 | 사망·중상 재해사례 **2,574건** (2013~2021) |
| 접속 방법 | 웹 브라우저 — PC·태블릿·스마트폰 모두 지원 |
| 이용 비용 | **무료** (서버 없음, 운영비 없음) |
| 배포 주소 | https://dodostudy.github.io/sif-program/ |

## Ⅱ. 개발 배경 및 경위

### 1. 문제 인식

○ 건설공사 착공~준공 全 공정의 기인물·재해형태를 체계적으로 정리한 표준 위험성평가 자료 **부재**  
○ 현장 실무자는 경험에 의존하거나 방대한 문서를 수동 탐색해야 하는 구조적 한계 상존  
○ 발주자의 위험성평가 검토 요청 시 데이터 근거가 없어 대응 역량 부족

### 2. 해결 방향 — KOSHA SIF 데이터 활용

한국산업안전보건공단(KOSHA) SIF 자료에서 돌파구 확인

> 공신력 있는 국가 기관이 구축한 실제 사고사례 기반 데이터로,  
> **12개 공종 · 49개 작업명 · 113개 단위작업명 · 58개 기인물** 이 체계적으로 분류되어 있음  
> 단, PDF·엑셀 형태로만 존재하여 현장 즉시 활용에 한계 — **웹 시스템으로의 전환을 자체 추진**

### 3. 개발 경위

```
STEP 1   KOSHA 공단에 Raw 데이터 직접 요청 · 확보
         ↓
STEP 2   텍스트마이닝으로 재해유형 · 재해형태 신규 항목 추출 · 구조화
         (2,574건 전수 데이터화 — 기존 PDF에 없는 분석 차원 추가)
         ↓
STEP 3   웹 시스템 자체 설계 · 개발 · 테스트
         (HTML/CSS/JS 기반, 외부 비용 없이 자체 구축)
         ↓
STEP 4   GitHub Pages를 통한 공개 배포 완료
         (URL 1개로 전 임직원 · 협력업체 즉시 접근 가능)
```

## Ⅲ. 시스템 특장점

### 1. 기술적 차별점

#### ① Raw 데이터 직접 확보 + 텍스트마이닝으로 가치 극대화

기존 KOSHA 자료에는 없던 **재해유형·재해형태 항목을 텍스트마이닝으로 신규 생성**,  
공정 × 기인물 × 재해형태의 **3차원 교차 분석**을 처음으로 가능하게 함

#### ② 서버·비용 없는 즉시 배포 구조

```
일반적인 웹 시스템                      본 시스템
─────────────────────────              ─────────────────────────
서버 구축 · 운영비 발생         VS      GitHub Pages 정적 배포
DB 관리 필요                            JSON 파일 내장 (3MB)
IT 부서 협조 필요                       URL 1개로 즉시 공개
배포까지 수개월                         git push → 1분 내 반영
```

#### ③ KOEN 발전소공정 특화 필터 내장

전체 2,574건 중 KOEN 발전소공정 해당 데이터를 별도 식별하여  
발전소 관할 공사에 최적화된 위험요인만 선별 조회 가능

### 2. 사용자 경험 차별점

#### 현장 실무자도 3단계면 위험성평가 완성

```
공종 선택  →  작업명 선택  →  기인물 선택
                                    ↓
              위험요인 Top 10 자동 도출
              재해개요 · 재해유발요인 · 위험성감소대책 즉시 확인
              → 인쇄 한 번으로 위험성평가 완성
```

#### 검색 한 번으로 연관 정보 전체 확인

- 기존: 공정 → 기인물 → 대책을 각각 다른 문서에서 수동 탐색  
- 본 시스템: 5단계 cascading 필터 → 관련 재해사례·차트·대책이 한 화면에 즉시 제공

| 페이지 | 기능 | 주요 사용자 |
|--------|------|-------------|
| 소개 | 시스템 배경·차별점 안내 | 전체 |

| 공정조회 | 공종·작업명·단위작업명 5단계 필터 + 사례 테이블 | 안전관리자, 발주담당자 |

| **위험성평가 생성** | 3단계 위자드 → 위험요인 자동 도출 + 인쇄 | **현장 근로자, 협력업체** |

## Ⅴ. 기대효과 및 활용 계획

### 즉각적 효과

○ 위험성평가 작성 소요시간 대폭 단축 — 데이터 탐색(수 분) → 3단계 위자드(수 초)로 전환  
○ 발주자 검토 시 객관적 데이터 근거 확보로 안전관리 대응 역량 강화  
○ 협력업체 TBM·안전교육 자료를 현장에서 즉시 출력 활용

### 확산 및 발전 계획

○ 유관 발전본부·사업소에 시스템 공유 및 활용 확산 **추진**  
○ 연간 재해 데이터 업데이트를 통한 시스템 고도화 **지속 추진**  
○ 국민 누구나 활용 가능한 공개 플랫폼으로 국가 중대재해 감소에 **기여**  
○ AI GPTs '안전누리' 연동 등 스마트 안전관리 기능 지속 **확대 추진**

## Ⅵ. 종합

> 본 시스템은 **공신력 있는 국가 안전 데이터(KOSHA SIF)를 텍스트마이닝으로 구조화하고,  
> 현장 누구나 즉시 활용할 수 있는 웹 플랫폼으로 자체 개발·공개 배포**한 것으로,  
> 단순 디지털 전환을 넘어 **데이터 기반 위험성평가 문화 정착의 실질적 출발점** 마련에 **기여**

○ 외부 예산·IT 인프라 없이 안전관리 실무 역량만으로 자체 구축·배포  
○ 발전소 건설현장의 현장 특성을 반영한 맞춤형 안전 디지털 플랫폼으로 지속 **운영 추진**

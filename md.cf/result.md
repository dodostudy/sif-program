## 1. 배경 — 왜 만들었는가

### 문제 인식

건설공사 착공부터 준공까지, **전 공정의 기인물과 재해형태를 아우르는 표준 위험성평가 자료가 없었다.**  
현장 실무자는 경험에 의존하거나 두꺼운 PDF·엑셀 문서를 뒤적여야 했고, 누락 위험요인을 체계적으로 점검할 방법이 없었다.

### 해결의 실마리

한국산업안전보건공단(KOSHA)의 SIF(Serious Injury & Fatality) 데이터에서 돌파구를 찾았다.

> KOSHA SIF 자료는 **공신력 있는 실제 사고사례** 기반으로,  
> 공종·작업명·단위작업명 3단계 분류 체계와 기인물·재해형태·개선대책까지  
> 위험성평가에 필요한 모든 정보를 구조적으로 담고 있다.

| KOSHA SIF 자료의 강점 | |
|---|---|
| 공신력 있는 기관 자료 | 산업안전보건공단이 구축한 국가 공인 안전 기초자료 |
| 체계적 공정 분류 | 공종→작업명→단위작업명 3단계, 위험성평가 기준자료로 즉시 활용 가능 |
| 기인물 정보 포함 | 공정별 주요 위험원(기인물)이 정리되어 구조적 파악 가능 |
| 사고사례 기반 접근 | 실제 사고 기반으로 현장의 위험을 현실적으로 이해 |
| 개선대책 연계 | 위험요인 파악에서 실질적 예방대책 수립까지 즉시 연계 |
| 경험을 초월하는 통합 정보 | 전기·기계·건축·토목 등 다양한 분야를 아울러, 경험의 경계를 넘는 위험 인식 |

### 개발 과정 (4단계)

```
① 문제 인식
   전 공정 기인물·재해형태를 아우르는 표준 위험성평가 자료 부재 확인
   ↓
② 해결의 실마리
   KOSHA SIF 자료에서 12개 공종 · 49개 작업명 · 113개 단위작업명 · 58개 기인물 체계 발견
   ↓
③ 데이터 확보 · 구조화
   공단에 Raw 데이터 직접 요청 확보
   → 텍스트마이닝으로 재해유형·재해형태 신규 항목 추출·구조화 (2,574건)
   ↓
④ 웹 시스템 구축
   PDF·엑셀 자료를 웹으로 전환
   → 현장 실무자·협력업체·안전담당자 누구나 무료로 즉시 활용 가능한 플랫폼 완성
```

## 2. 시스템 소개

**발전소·건설공사 현장의 위험성평가 검토와 생성을 지원하는 데이터과학 기반 웹 시스템**

공정 → 기인물 → 재해형태의 다차원 연계 분석으로,  
누락 위험요인 점검부터 위험성평가 작성까지 체계적이고 내실 있는 안전관리를 지원합니다.

### 주요 활용 목적

- **위험성평가 검토** — 발주자의 검토·보완 요청을 데이터 근거로 뒷받침
- **위험성평가 생성** — 공정별 위험성평가 초안 작성 지원
- **TBM·안전교육** — 작업 전 현장 교육 자료 즉시 출력
- **안전조치 근거자료** — 개선 요구 시 객관적 데이터 근거 제공

## 3. 개발 내용

### 페이지 구성 (6페이지)

| 페이지 | 주요 기능 |
|--------|-----------|
| **소개** | 시스템 배경·차별점·기능 안내 |
| **대시보드** | 요약 카드 3종 + 도넛·수평바·히트맵 차트, KOEN 발전소공정 필터 |
| **공정조회** | 공종→작업명→단위작업명 5단계 cascading 필터 + 재해사례 테이블 + 엑셀 다운로드 |
| **기인물조회** | 기인물 역방향 조회(12대/분류/기인물) → 공종·재해형태 분포 차트 |
| **재해형태분석** | 재해형태별 다차원 연계 필터 + 기인물·공종별 심층 차트 |
| **위험성평가 생성** | 3단계 카드 위자드 → 위험요인 Top10 + 재해사례·대책 자동 제시, 인쇄 지원 |

### 핵심 기술 구조

```
데이터 흐름
Excel (source/) → convert-excel.py → db.json (2,574건) + dropdown-ref.json
         ↓
브라우저 인메모리 캐시 (DataLoader)
         ↓
cascading 필터 (FilterManager · Observer 패턴)
         ↓
aggregateBy / topN → ChartManager / buildTable → 화면 렌더링
```

## 4. 차별점

기존 PDF·엑셀 기반 자료와 근본적으로 다른 4가지 차별점

| # | 차별점 | 내용 |
|---|--------|------|
| 1 | **텍스트마이닝 기반 신규 데이터 생성** | KOSHA Raw 데이터에 없던 재해유형·재해형태 정보를 텍스트마이닝으로 추출해 신규 열로 추가 → 다차원 분석 가능 |
| 2 | **위험성평가 실무 최적화** | 검토·생성 과정에서 누락된 공정·기인물·재해형태를 즉시 식별 가능한 구조로 설계 |
| 3 | **웹 기반 접근성 확대** | PDF·엑셀 → 웹 전환으로 현장 실무자·협력업체·안전담당자 모두 시간·장소 제약 없이 활용 |
| 4 | **공개 플랫폼으로 확장** | 국민 누구나 무료로 활용 가능, 국가 중대재해 감소에 기여하는 공공적 가치 |

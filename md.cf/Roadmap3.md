## 0. 배경 및 목표

한국산업안전보건공단이 **산업재해 고위험요인(SIF) 아카이브(2026-04-01)** 를 갱신하면서,
기존 프로그램의 데이터 소스를 **전국 건설업 3,459건**으로 확장할 수 있게 되었다.

| 목표 | 내용 |
|------|------|
| ① 데이터 최신화 | 기존 2,574건 → 신규 공단 건설업 **3,459건 (+885건, +34%)** |
| ② 파생 컬럼 복원 | 신규 원본에 없는 6종 파생 데이터를 **재계산·이식**하여 현 기능 100% 유지 |
| ③ 범위 이원화 | **전국 건설업 ↔ KOEN(남동발전) 공정** 토글 지원 |
| ④ 무중단 | 정적 사이트 구조·CDN 스택 유지, GitHub Pages 배포 방식 불변 |

## 2. 아키텍처 방침

- **데이터 소스 단일화**: 신규 공단 아카이브(건설업)를 유일 원본으로 채택. 기존 2,574건은 파생룩업·매핑 참조용으로만 보존.
- **파생 재구성은 빌드타임**: `convert-excel.py`가 신규 시트를 읽어 파생 6종을 재계산·이식하여 `db.json` 생성. 브라우저 런타임 로직은 최소 변경.
- **범위 토글은 런타임 필터**: `KOEN공정` 불리언 컬럼 + 전역 스코프 토글(전국/KOEN)로 처리. 데이터는 하나, 필터만 분기.
- **매핑 테이블은 코드 밖으로**: 수동 보완이 필요한 매핑(기인물분류 17건, 공종 정규화, 재해형태 정규화, 신규공종 KOEN 판정)을 `scripts/mapping/*.json`으로 분리하여 검수·유지보수 용이화.

## Phase 1 — 데이터 파이프라인 재구축 (기반)

### 1.1 신규 파서 작성
- `scripts/convert-excel.py`를 신규 소스로 전환
  - `SOURCE_FILE` → 공단 아카이브 xlsx, 시트 `아카이브(건설업)`
  - **헤더 3행·병합셀** 대응 (데이터는 4행부터, col1~col9)
  - 신규 컬럼 순서 매핑: `연번/공종/작업명/단위작업명/재해종류/재해개요/기인물/재해유발요인/위험성감소대책`

### 1.2 매핑 테이블 구축 (`scripts/mapping/`)
- `gongjong-normalize.json` — 공종 표기/재편 정규화 (12.공통 → 12/13 규칙 포함)
- `giinmul-class.json` — 기인물 → 기인물분류/12대 (기존 40 + 신규 17 보완)
- `jaehae-normalize.json` — 재해종류 ↔ 기존 재해형태 명칭 매핑
- `koen-scope.json` — 작업명/단위작업명 → KOEN 해당여부 (신규 공종 판정 포함)

### 1.3 파생 컬럼 재계산 로직
- `기인물분류`·`12대기인물` ← `giinmul-class.json` 룩업
- `KOEN공정` ← `koen-scope.json` 룩업 (기본값 정책 명시)
- `위험도순위`·`3년간사고비중` ← 신규 3,459건 빈도 **재집계**
- `혹서기` ← `재해개요` 정규식으로 `YYYY년 MM월` 추출 → 6~9월/12~2월 매핑

### 1.4 산출물 갱신
- `data/db.json` (3,459건, 파생 복원)
- `data/dropdown-ref.json` (신규 13공종 계층·기인물맵)
- **산출물 검증 리포트** 자동 출력 (건수·분류수·미매칭 목록)

**완료 기준:** db.json 3,459건, 파생 6종 전량 채움, 미매칭 0 또는 명시적 판정 완료.

## Phase 2 — 프런트엔드 정합성 확보 (현 기능 유지)

### 2.1 하드코딩 공종 문자열 점검
- 전 페이지·JS에서 `12. 공통공사`, `철근콘크리트공사`, `전기, 기계설비공사` 등 **구 표기 참조 전수 검색·치환**
- 신규 13공종 반영 (드릴다운·발전소공정 토글·사이드바)

### 2.2 재해형태 명칭 정합
- 차트 라벨·필터·범례에서 재해형태 표기 통일 (정규화 매핑 반영)

### 2.3 사전집계 CSV 재생성
- `data/csv/` 10종을 신규 3,459건 기준으로 재집계 (기존 CSV 스키마 유지)
- 관련 페이지(통계/기인물조회) 로딩 검증

**완료 기준:** 대시보드·공정조회·기인물조회·위험성평가 4개 페이지 무오류 렌더, 차트·필터 정상.

## Phase 3 — 전국/KOEN 범위 토글 (신규 기능)

### 3.1 전역 스코프 상태
- `FilterManager`에 최상위 `scope` 상태 추가 (`전국` | `KOEN`)
- `KOEN` 선택 시 `filterDB`가 `KOEN공정=true`만 통과

### 3.2 UI
- 헤더/사이드바 상단에 **범위 토글** 배치 (다크테마 토글과 동일 패턴)
- 선택 상태 `localStorage` 저장, 요약카드에 "전국 3,459건 / KOEN 2,530건" 표기

### 3.3 카스케이딩 연동
- 스코프 변경 시 하위 필터·차트 전체 재계산 (Observer notify)

**완료 기준:** 토글 전환 시 건수·차트가 즉시 갱신, 새로고침 후 상태 유지.

## 0. 배경과 목표

한국산업안전보건공단이 SIF 아카이브를 갱신(2026-04-01)했고, 이를 사이트 스키마에 맞춰 전처리한 산출물(2026-09-08)이 준비됐다. **기존 프로그램의 구조·화면·관례는 그대로 두고**, 데이터를 갈아끼운 뒤 신규 열이 열어주는 정보를 탭으로 덧붙인다.

| # | 목표 | 내용 |
|---|------|------|
| ① | **최신 데이터 교체** | 2,574건(2013~2021) → **3,459건(~2023)**, 13공종·57기인물·16재해형태. 기존 6개 페이지 무오류 유지 |
| ② | **신규 정보 탭 추가** | 신규 열(추락고·발생시기·재해정도 등)과 T-테이블(고위험조합·대표사례·프로파일)을 **사이드바 신규 그룹 "심층 분석"** 으로 제공 |
| ③ | **추락 높이 분석** (요청 핵심) | 떨어짐 사고를 **높이 구간 토글**로 나눠 사망·중상 건수·기인물·공종을 별도로 보는 페이지 |
| ④ | **위험성평가 생성 강화** | 대표사례·감소대책 후보·누락점검을 위저드에 결합 — "참고 자료"에서 "작성 보조"로 |
| ⑤ | **영문 모드 종료** | EN 모드 폐기(사용자 결정). 번역 자산·스크립트 제거, 코드는 무해한 스텁으로 유지 |

**원칙 (변경 금지)**
- 필터·집계·등식비교는 **한글 canonical 값**, 화면 표시만 가공 (기존 최상위 규칙)
- `db.json`은 손으로 고치지 않는다 — 항상 스크립트로 재생성
- 정적 사이트(GitHub Pages)·CDN 스택·`FilterManager`/`ChartManager`/`DataLoader` 관례 유지
- 발전소공정(KOEN) 토글은 **전 페이지 공통 스코프** — 신규 지표도 토글을 따라 재계산되어야 한다

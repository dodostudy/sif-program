SIF 아카이브 신버전 변환 가이드

공단 원본 CSV를 주피터로 불러온 상태에서 시작해, 전처리 → 기존 열구조(15열) 저장 → 확장 열구조(28열) 저장 순으로 진행하는 절차입니다. 함께 드린 주피터 노트북의 셀 순서와 그대로 대응합니다.

입력 공단 원본 csv · 구_db.json 출력 15열·28열 각 xlsx / csv / json 행수 3,459

이 문서를 읽는 법

단계마다 무엇을 하는지 → 코드 → 무엇을 확인해야 하는지 순서로 적었습니다. 노트북에는 각 단계 끝에 assert가 붙어 있어, 셀이 오류 없이 끝나면 그 단계는 검증을 통과한 것입니다.

변환 전체를 관통하는 원칙이 하나 있습니다. 원문에서 읽어낼 수 없는 값은 채우지 않고 비웁니다. 추락 높이가 적히지 않은 사고에 평균값을 넣거나, 결과가 서술되지 않은 사고를 사망으로 처리하면 그 순간부터 데이터가 아니라 추정이 됩니다. 논문 심사에서 산출식을 물었을 때 답할 수 없는 칸은 만들지 않았습니다.

신버전 원본 CSV 로드·정규화

공단 원본은 위쪽 몇 행이 제목과 병합 헤더입니다. header=None으로 읽고 연번이 있는 행을 찾아 그 아래부터 9열을 잘라냅니다. 인코딩은 utf-8-sig → cp949 순으로 시도합니다.

def load_sif(path):
    raw = pd.read_csv(path, header=None, encoding='utf-8-sig', dtype=str)
    for i in range(10):                          # '연번' 셀이 있는 행 = 헤더
        row = raw.iloc[i].astype(str).str.strip().tolist()
        if '연번' in row: hdr, col0 = i, row.index('연번'); break
    df = raw.iloc[hdr+1:, col0:col0+9].copy()
    df.columns = ['연번','공종','작업명','단위작업명','재해종류',
                  '재해개요','기인물','재해유발요인','위험성감소대책']
    df = df.dropna(subset=['재해개요']).reset_index(drop=True)
    for c in df.columns:                        # 앞뒤 공백 제거
        if c != '연번': df[c] = df[c].astype(str).str.strip()
    return df

추락고 추출

이 단계가 가장 주의를 요합니다. 숫자와 m만 보고 뽑으면 부재 길이와 간격까지 높이로 잡힙니다.

표기판정이유

U  = r'(?:m|M|미터)(?![mM])'
HP = [re.compile(r'[Hh]\s*[≒=≈:：]\s*약?\s*([0-9]+(?:\.[0-9]+)?)\s*' + U),
      re.compile(r'높이\s*[:：]?\s*약?\s*([0-9]+(?:\.[0-9]+)?)\s*' + U),
      re.compile(r'약?\s*([0-9]+(?:\.[0-9]+)?)\s*' + U + r'\s*아래')]

def fall_height(s):
    for P in HP:
        m = P.search(str(s))
        if m: return float(m.group(1))
    return None          # 앵커 없으면 비움

to_records는 numpy 타입을 파이썬 기본형으로 바꿉니다. 그대로 내보내면 true 대신 문자열이 되거나 정수가 1.0으로 나가서 사이트에서 === true 비교가 조용히 깨집니다.

for k, v in r.items():
    if   isinstance(v, (np.bool_, bool)):       v = bool(v)
    elif isinstance(v, np.integer):            v = int(v)
    elif isinstance(v, (float, np.floating)):  v = None if pd.isna(v) else (int(v) if k in INT_COLS else float(v))

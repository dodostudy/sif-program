SIF 시스템 탑재 테이블 변환 가이드

확장열 파일(3,459건 28열)에서 시스템에 심을 테이블 7개를 어떻게 뽑았는지, 순서대로 코드와 함께 적었습니다. 전부 build_tables.py 한 파일에 들어 있고, 입력을 바꿔 다시 돌리면 같은 규칙으로 재생성됩니다.

입력 SIF_신버전_확장열_3459건.json출력 T1~T6 · T4m (xlsx · csv · json)코드 build_tables.py

전체 흐름

확장열 28열 (T0) ├─ T1 기인물프로파일 기인물 × 재해형태 교차표 → long 형 + 유형 판정 ├─ T2 공종기인물후보 공종별 기인물 순위 · 누적비율 ├─ T3 고위험조합 공종×기인물×재해형태 빈도 → 등급 + 표준화잔차 ├─ T4 대표사례 칸별 군집 → medoid │ └─ T4m 매핑 모든 사례 id → 하위유형 소속 ├─ T5 감소대책항목 ▶ 단위 분해 + 출현건수 └─ T6 기인물마스터 사망건수 순 정렬 + 드롭다운 라벨

T1~T3·T5·T6는 집계이고 결정적입니다. 같은 입력이면 항상 같은 결과가 나옵니다. T4만 군집 알고리즘이 들어가는데 random_state=0으로 고정해 재현됩니다.

준비

import pandas as pd, numpy as np, json
from scipy.stats import chi2_contingency
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.cluster import KMeans
from sklearn.metrics.pairwise import cosine_similarity

d = pd.DataFrame(json.load(open('SIF_신버전_확장열_3459건.json', encoding='utf-8')))
N = len(d)      # 3459

기존열구조(15열)가 아니라 확장열을 입력으로 쓰는 이유는 T6의 최근5년건수에 발생연도가, T4 정보충실도에 추락고_m·감소대책_항목수가 필요하기 때문입니다.

T1

기인물프로파일 — 기인물 × 재해형태 분포

교차표를 만든 뒤 세로로 풀어 기인물 한 종 × 재해형태 한 종 = 한 행이 되게 합니다. 시스템에서 WHERE 기인물 = ?로 조회하면 그 기인물의 재해형태 분포가 그대로 나옵니다.

ct = pd.crosstab(d['기인물'], d['재해형태'])
meta = d.drop_duplicates('기인물').set_index('기인물')[['기인물분류','12대기인물']]
rows = []
for k in ct.index:
    r = ct.loc[k]; n = int(r.sum()); top = r.idxmax(); tp = r.max() / n
    유형 = '단일형' if tp >= .8 else ('혼합형' if tp >= .5 else '분산형')
    for f, c in r[r > 0].sort_values(ascending=False).items():
        rows.append([k, meta.loc[k,'기인물분류'], bool(meta.loc[k,'12대기인물']),
                     n, 유형, top, round(tp*100,1), f, int(c), round(c/n*100,1)])
T1 = pd.DataFrame(rows, columns=['기인물','기인물분류','12대기인물','기인물건수','프로파일유형',
                                 '1위재해형태','1위비율','재해형태','건수','비율'])

T2

공종기인물후보 — 공종별 기인물 순위

공종마다 기인물을 건수 순으로 세우고 누적비율을 붙입니다. 시스템에서 공종만 알 때 누적비율 <= 80으로 끊으면 그 공종의 주요 기인물 후보가 나옵니다.

rows = []
for (code, name), sub in d.groupby(['공종코드', '공종']):
    vc = sub['기인물'].value_counts(); cum = 0
    for k, (kk, c) in enumerate(vc.items(), 1):
        p = c / len(sub) * 100; cum += p
        rows.append([code, name, len(sub), k, kk, int(c), round(p,1), round(cum,1)])
T2 = pd.DataFrame(rows, columns=['공종코드','공종','공종건수','순위','기인물','건수','공종내비율','누적비율'])

T3

고위험조합 — 등급과 표준화잔차

공종×기인물×재해형태 3항 조합의 빈도를 세고 두 가지 지표를 붙입니다.

등급 — 누적비율로

c = d.groupby(['공종코드','공종','기인물','재해형태']).size().sort_values(ascending=False).reset_index()
c.columns = ['공종코드','공종','기인물','재해형태','건수']
c['비율'] = (c['건수'] / N * 100).round(2)
c['누적비율'] = c['비율'].cumsum().round(1)
c['등급'] = np.where(c['누적비율'] <= 50, 'A', np.where(c['누적비율'] <= 80, 'B', 'C'))

표준화잔차 — 공종 크기를 감안한 특이성

빈도만 보면 큰 공종이 항상 위에 옵니다. 공종×기인물 교차표에서 카이제곱 기대빈도를 구하고, 관측이 기대보다 얼마나 큰지를 표준화잔차로 봅니다. 3 이상이면 통계적으로 유의하게 과다한 조합입니다.

ctg = pd.crosstab(d['공종'], d['기인물'])
chi2, p, dof, exp = chi2_contingency(ctg)
res = pd.DataFrame((ctg - exp) / np.sqrt(exp), index=ctg.index, columns=ctg.columns)
c['공종기인물_표준화잔차'] = [round(res.loc[a, b], 1) for a, b in zip(c['공종'], c['기인물'])]
c['특이조합'] = c['공종기인물_표준화잔차'] >= 3

T4

대표사례 — 칸별 군집과 medoid

기인물×재해형태 한 칸에 사례가 100건 넘게 몰리는 경우가 있어, 그대로 보여주면 쓸 수 없습니다. 칸 안에서 재해유발요인 문장을 군집화해 상황이 다른 하위 유형을 나누고, 각 유형에서 가장 전형적인 1건(medoid)을 대표로 뽑습니다.

칸 크기군집 수해당 칸
100건 이상58
30~99건318
30건 미만1 (군집 없이 medoid)216
vec = TfidfVectorizer(analyzer='char_wb', ngram_range=(2,4), min_df=1)
rows, memb = [], []
for (k, f), cell in d.groupby(['기인물', '재해형태']):
    cell = cell.reset_index(drop=True); n = len(cell)
    X = vec.fit_transform(cell['재해유발요인']); S = cosine_similarity(X)
    kk = 5 if n >= 100 else (3 if n >= 30 else 1)
    labels = KMeans(n_clusters=kk, n_init=10, random_state=0).fit(X).labels_ if kk > 1 else np.zeros(n, dtype=int)
    for g in range(kk):
        idx = np.where(labels == g)[0]
        typ = S[np.ix_(idx, idx)].mean(axis=1)          # 군집 내 평균 유사도 = 전형성
        m = idx[typ.argmax()]                            # medoid
        rows.append([k, f, n, g, len(idx), int(cell.loc[m,'id']), cell.loc[m,'재해유발요인'], round(float(typ.max()),3)])
        for i in idx: memb.append([int(cell.loc[i,'id']), k, f, g, i == m])
T4  = pd.DataFrame(rows, columns=['기인물','재해형태','칸건수','하위유형번호','하위유형건수','대표사례id','대표사례_재해유발요인','전형성'])
T4['하위유형명'] = ''          # 사람이 붙임
T4m = pd.DataFrame(memb, columns=['id','기인물','재해형태','하위유형번호','대표사례여부'])

글자 2~4그램 TF-IDF를 쓰는 이유는 형태소 분석기 없이도 한국어 유사도가 잘 잡히고, 환경 의존성이 없어서입니다. random_state=0이라 다시 돌려도 같은 군집이 나옵니다.

사람이 할 일 — 하위유형명은 비어 있습니다. 군집이 실제로 다른 상황인지는 대표사례 문장을 읽고 판단해 이름을 붙이셔야 합니다. 예: 비계×떨어짐의 5개 군집은 "이동 중 · 개구부 · 단부 · 수평재 위 · 안전대 미착용"으로 갈립니다.
확인 — T4 310행(칸 242개), T4m 3,459행. 모든 사례가 정확히 한 하위유형에 속하고, 하위유형마다 대표사례가 1건씩입니다.
T5

감소대책항목 — 문장 단위 분해

원본 감소대책은 한 셀에 ▶로 구분된 여러 항목이 들어 있습니다. 한 항목 = 한 행으로 풀고, 같은 문장이 전체에서 몇 번 나오는지 붙입니다.

rows = []
for _, x in d.iterrows():
    items = [s.replace('▶', '').strip() for s in x['위험성감소대책'].split('\n') if s.strip()]
    for j, s in enumerate(items, 1):
        rows.append([int(x['id']), j, s])
T5 = pd.DataFrame(rows, columns=['id','항목순번','감소대책문장'])
T5['문장출현건수'] = T5['감소대책문장'].map(T5['감소대책문장'].value_counts())
확인 — 10,578행. 고유 문장 3,149개이고 그중 2,335개는 한 번만 나옵니다. 표준화 전 단계입니다.
T6

기인물마스터 — 드롭다운용

기인물 57종을 사망건수 내림차순으로 세우고, 선택 화면에 필요한 보조 정보를 붙입니다.

g = d.groupby('기인물'); ct = pd.crosstab(d['기인물'], d['재해형태'])
T6 = pd.DataFrame({
    '사망건수': g.size(),
    '기인물분류': g['기인물분류'].first(),
    '12대기인물': g['12대기인물'].first().astype(bool),
    '위험도순위': g['위험도순위'].first(),
    '1위재해형태': ct.idxmax(axis=1),
    '1위비율': (ct.max(axis=1) / ct.sum(axis=1) * 100).round(1),
    '주요공종': g['공종'].agg(lambda s: s.value_counts().index[0].split('. ',1)[-1]),
    '최근5년건수': d[d['발생연도'] >= 2019].groupby('기인물').size(),
}).fillna({'최근5년건수': 0})
T6 = T6.sort_values(['사망건수', '최근5년건수'], ascending=False).reset_index()
T6.insert(0, '순위', range(1, len(T6)+1))
T6['표시명'] = T6.apply(lambda r: f"{r['기인물']} ({r['사망건수']}건{' ·12대' if r['12대기인물'] else ''})", axis=1)
확인 — 57행. 표시명이 드롭다운 라벨, 기인물이 다른 테이블과의 조인 키입니다.
